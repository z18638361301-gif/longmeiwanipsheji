# 龙美岩信

以龙美湾风岩地貌、侨批文化和台湾海峡为线索的沉浸式互动网页原型。

## 体验内容

- 电影感欢迎动画：从海峡俯瞰落入山石长廊
- 横向石纹长卷：落笔成信、驭舟过海、岩壁留存
- 家书写作：常用短语、公开信 / 密信选择、字数提示
- 岩纹海报：动态写入姓名、收信人、正文、海峡邮戳，可保存与分享
- 纸船小游戏：鼠标或手指掌舵，躲避海浪和暗礁
- 岩壁档案：公开信永久留纹、姓名检索；密信仅保存在当前设备
- 文旅闭环：公开信文创盲盒、门票与文创回顾码的前端展示

## 本地预览

这是一个无需安装依赖的静态网页。为确保海报保存功能正常，建议在项目目录启动任意本地静态服务器，再访问 `index.html`。

例如：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## GitHub Pages 部署

仓库名使用 `longmeiwanipsheji` 时，项目站点地址为：

```text
https://<你的 GitHub 用户名>.github.io/longmeiwanipsheji/
```

项目已在 `_config.yml` 中配置 `baseurl: "/longmeiwanipsheji"`。页面资源全部使用相对路径，因此部署到这个项目子路径后，图片、字体、音乐和脚本都能正常加载。

在 GitHub 仓库的 `Settings → Pages` 中选择从 `main` 分支的根目录发布即可。

## 文件结构

- `index.html`：页面结构与三幕体验
- `styles.css`：视觉系统、响应式布局和转场动画
- `app.js`：写信、海报、小游戏、检索与本地留存逻辑
- `assets/longmei-bay-hero.png`：龙美湾欢迎动画与岩信海报主视觉

说明：当前版本为高保真前端原型，公开信数据使用浏览器本地存储模拟。正式上线时需接入账号、内容审核、云端数据库、后台管理、二维码短链和分享平台配置。
